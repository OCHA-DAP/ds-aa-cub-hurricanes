10  CHIRPS-GEFS Precipitation Forecasts

CHIRPS-GEFS is the Climate Hazards Center’s 16-day daily precipitation forecast, published as global Cloud-Optimized GeoTIFFs (COGs). The forecast part of the trigger takes its rainfall from it. This chapter describes src/datasources/chirps_gefs.py, which downloads the forecasts for Cuba, stores them in blob storage and summarises them over the country. The next chapter goes through the processing for a single issue date.

10.0.1 How the module works

The rasters are clipped in two stages. On download, each global COG (about 7,200 × 3,600 pixels) is opened over HTTP and cut to Cuba’s bounding box (about 218 × 70 pixels) before it is written to blob storage. Because COGs can be read by window, only that box is transferred:

# ChirpsGefsDownloader.download_single_file
with rxr.open_rasterio(source_url) as da_global:
    da_aoi = da_global.rio.clip_box(*self.config.geometry.total_bounds)
    stratus.upload_cog_to_blob(da_aoi, blob_path)

When the stored rasters are processed, they are clipped again to Cuba’s actual boundary, which removes sea pixels inside the box:

# ChirpsGefsProcessor.process_spatial_mean
da_clipped = da_loaded.rio.clip(self.config.geometry.geometry, all_touched=True)
spatial_mean = da_clipped.mean(dim=["x", "y"]).values

The module has five classes:

  • ChirpsGefsConfig: the region geometry, date range, number of lead times and blob location.
  • ChirpsGefsDownloader: builds source URLs and blob paths, and downloads, clips and uploads files.
  • ChirpsGefsLoader: loads stored rasters, one at a time or as a lazily loaded (dask) time series.
  • ChirpsGefsProcessor: clips to the region geometry and computes spatial means.
  • ChirpsGefsManager: runs downloading and processing together.

manager = ChirpsGefsManager(

# Run the steps separately
